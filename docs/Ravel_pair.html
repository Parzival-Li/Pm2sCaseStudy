Default MUSTER truncates GT at the last matched onset. It evaluates 4,962 GT notes for Kharsel but 4,895 for Kotys, omitting 45 notes late in GT88 and 22 in GT89. Keeping auto_match unchanged and rescoring against complete GT yields MeanER 18.1228 for Kharsel and 29.2109 for Kotys, a gap of 11.0881 percentage points; Kotys miss increases from 1,348 to 1,415. This control harmonizes evaluation scope without replacing the original model scores.

Input MIDI is represented as SPR using real-second onsets and key releases, processed by the same ScorePerfmMatcher/ErrorDetection/Realignment chain, and counted using complete-GT note rules. This input control does not report Onset/OffsetER because performed key-release durations are not target notated values. Counts from independent alignments cannot be subtracted to obtain a note-level causal decomposition.

The input performances already differ: 659 versus 444 misses and 213 versus 103 pitch errors. The gap widens after XML conversion, especially for extras, from 211 versus 198 in MIDI to 774 versus 338 in XML. In the scores, Kotys more often omits the lower continuous arpeggio line and regroups remaining notes onto different chord/beat positions. Kharsel preserves more material but still contains many duration and enharmonic spelling errors.
